# 見た目のデザインの決まりと前提

QLoop のロゴ・アイコン・配色・画面の見た目の決まりと、見直すときの前提をまとめる。0.3.0 の見た目は、2026-10-11 に Claude Design で決めたもの（配色は瑠璃 × 生成り）。値の正本は `src/ui/app.css` の先頭の CSS 変数（デザイントークン）で、この文書には主な値だけを書く。機能の仕様は `docs/design.md` にある。

## 1. アプリの概要

- QLoop は 1 問 1 答で日本史の年表や語彙を覚える PWA（ホーム画面に追加して使う Web アプリ）。名前は Question と Loop（くり返し）から。
- 使う人は、中学受験を目指す小学校高学年から大人まで。表示は大人向けの通常の UI でよく、幼い雰囲気にはしない。ふりがなは付けない。
- 使い方は、1 回 10 問ほどの短い出題を毎日くり返す。間違えた問題は「復習」でくり返し出る。
- 端末は iPhone の縦向きだけ。対応の下限は iOS 15.8（iPhone 7、画面の幅 375px）。新しい端末の例は iPhone 16 Pro（幅 402px）。

## 2. 画面と要素

各画面の上部は、「戻る」の行（押せる高さ 44px）と、その下の大きな見出し。下に固定する帯は、画面の背景と同じ色で、上に線を引く。

| 画面 | 主な要素 |
|---|---|
| ホーム | ロゴとその右の連続学習日数（全教材で共通）、教材のカード（上から教材の切り替え（教材が 2 つ以上のとき）、教材名、件数、「出題」、一覧（年表は「年表を覚える」、語彙は「言葉を覚える」）・復習・成績の行（復習には件数の札。0 件なら出さない）。「日本史年表」は出題できる出来事 371 件と基本の年表 129 件、語彙は出題できる言葉 314 件と基本の語彙 86 件）、下部に版と「アプリを更新」（押すと、その下に「最新の版です」などの結果が出る）。上部に帯が出ることがある（ホーム画面への追加を促す帯、新しいバージョンの帯） |
| 出題設定 | 出題する出来事（切り替えボタン: 基本の年表のみ / すべて）、出題パターン（2 列のカード 4 枚。名前と説明: 年号入力「年を数字で入れる」、年号 4 択「4 つの年から選ぶ」、出来事 4 択「4 つの出来事から選ぶ」、ミックス「3 つの形式をまぜる」）、問題数（切り替えボタン: 10 問 / 20 問 / 全問）、範囲（切り替えボタン: 全範囲 / 年号の範囲 / 時代。年号の範囲は開始年と終了年の欄、時代は 3 列のチップ）。語彙は出題する言葉（基本の語彙のみ / すべて）、出題パターン（2 列のカード 3 枚。意味 4 択「4 つの意味から選ぶ」、言葉 4 択「4 つの言葉から選ぶ」、ミックス「2 つの形式をまぜる」）、問題数、範囲（全範囲 / 種類。種類は母集団に言葉があるものをチップで選ぶ）。下に固定する帯に対象の件数と「開始」 |

| 出題: 年号 4 択 | 年号入力と同じ問題のカード、年号の選択肢 4 つ（2 列 2 段、小さい順） |
| 出題: 出来事 4 択 | 「1467年の出来事は？」（数字を大きく）、選択肢 4 つ |
| 出題: 意味 4 択 | 「どんな意味？」と言葉を大きく出すカード、意味の選択肢 4 つ |
| 出題: 言葉 4 択 | 「この意味の慣用句は？」（種類の名前を入れる）と意味のカード、言葉の選択肢 4 つ |

| 結果 | 得点のカード（正答の割合の輪のグラフと「7 / 10」、問題数が 20 以下なら 1 問ずつの判定の区切り、予定の問題数）、間違えた出来事と正解の年の一覧（行は押せて、一覧のその出来事に移る）。語彙は間違えた言葉・読み（ある場合）・意味の順の一覧。下に固定する帯に「ホームへ」 |
| 一覧 | 上部に「表示する出来事」（切り替えボタン: 基本の年表のみ / すべて）、時代のチップ（3 列。母集団に出来事がある時代だけ。何も選ばなければ全部）、「隠す」（切り替えボタン: 隠さない / 年 / 出来事）、表示中の範囲と件数（「すべての時代 371 件」「昭和・平成 91 件」）。時代ごとの見出し（絞り込んだ後の件数付き。カードの外に置き、スクロールしても上に留まる）と、時代ごとのカードの行（左に年、右に出来事。隠した部分は「？」の灰色の札で、行を押すと出て、もう一度押すと隠れる。復習の候補の行には「復習」の札）。語彙は「表示する言葉」、種類のチップ、「隠す」（隠さない / 意味 / 言葉）、種類の見出し、行は 1 段目に言葉と読み、2 段目に意味。結果画面から開いたときは該当の行を薄い瑠璃の背景で強調し、下に固定する帯に「結果に戻る」を出す |
| 成績 | 切り替えボタン（全体 / 出来事別 / 履歴）。全体: 総回答数・正答率・連続学習日数、時代別の横棒、記録の管理（書き出し・読み込み・リセット）。出来事別: 並べ替え（選ぶ欄）と一覧（371 行。行を開くとパターン別の内訳）。語彙は言葉別（言葉と、その下に読み（ある場合）・種類・回答数・最終回答日）、種類別の横棒、意味 4 択と言葉 4 択の内訳。履歴: セッションの一覧（選んだ教材のパターンと範囲の表示）。教材が 2 つ以上のとき、記録の管理に「書き出し・読み込み・リセットは、すべての教材の記録をまとめて扱います。」と出す |
| 確認ダイアログ | 終了・読み込み・リセットの確認（左に取り消し、右に実行。リセットだけ実行のボタンを赤にする） |

## 3. 守ってほしいこと

画面:

- 幅 375px で横スクロールを出さず、402px でも崩れないこと。縦向きだけを考える。
- 年号入力と年号 4 択の問題文、出来事 4 択の選択肢は、全角 15〜30 字ほど（上限 36 字）の 1 文。語彙の意味（意味 4 択の選択肢と言葉 4 択の問題文）は、上限 30 字の 1 文。幅 375px では 2 行になることが多いので、2 行でも読みやすく、選択肢 4 つと判定の帯が 1 画面（375 × 667）に収まるようにする。
- 押せる部分の高さは 44px 以上。主な操作のボタン（出題・開始・次へ・ホームへ）は 48px 以上。
- 文字は端末の標準フォント（ヒラギノ角ゴシック）を使う。日本語の Web フォントは数 MB あり、オフライン用のキャッシュが膨らむので使わない。太さは 400・600・700 の 3 つ。数字の並ぶ所は等幅の数字（`font-variant-numeric: tabular-nums`）にする。
- 本文は 16px 以上。入力欄の文字も 16px 以上にする（16px 未満だと、iOS が入力のたびに画面を拡大する）。
- 文字と背景のコントラストは 4.5:1 以上（補助の文字や「わからない」も含む。押せない状態の表示は除く）。
- 色の意味を変えない。正解は緑、不正解は赤、「わからない」は灰色。主な操作は瑠璃の 1 色にそろえる。元に戻せない操作（リセット）だけ、実行のボタンを赤にする。
- 写真や大きな画像は使わない。印は SVG で描く（`src/ui/components/icons.tsx`）。
- 今は明るい配色だけ。ダークモードは対象外（入れるなら、全画面の配色を 2 通り用意する）。
- 動きは控えめにする。判定の帯が下から上がる動き（150ms）だけにし、端末で動きを減らす設定のときは動かさない。

アイコンとロゴ:

- アイコンは正方形で、背景を塗りつぶす（透過にしない）。iOS が角を丸めて切り取るので、四隅に要素を置かず、形は中央の約 60% に収める。
- ホーム画面の小さな表示（約 60px）でも見分けられること。細い線や小さな文字は避ける。
- 書き出すサイズは 512px と 192px（manifest 用）、180px（iOS のホーム画面用）。元のデータは SVG か 1024px の PNG で用意する。
- 書き出した PNG と SVG は、生成元の来歴などのメタデータ（PNG の `caBX`・`tEXt` などのチャンク、SVG の `<metadata>`）を外してから `public/` に置く。
- ロゴは、ホーム画面の見出しに使う。フォントを使わない SVG にする（`public/qloop-logo.svg`。オフラインでも出るよう、事前キャッシュに入れる）。
- iOS の画面上部（時刻などの表示）の色は、`index.html` の `theme-color` と manifest の `theme_color`・`background_color` で決まる。画面の背景の色を変えるときは、これも合わせて変える。
- iOS は、ホーム画面に追加したときのアイコンを使い続けることがある。アイコンを変えた版では、端末で追加し直す必要がある（手順は `docs/operations.md` の 4 章）。

実装の都合:

- iOS 15.8 の Safari で動く CSS だけを使う。CSS のネスト、コンテナクエリ、`:has()`、`dialog` 要素は使えない。グラデーション、角丸、影、半透明、`:focus-within`、グリッド、flex の `gap` は使える。すりガラスの表現（`backdrop-filter`）は使えるが、古い端末では重くなるので控える。
- スタイルは `src/ui/app.css` の 1 ファイルにまとめ、先頭にデザイントークンを置く。
- 切り替えボタンと出題パターンのカード、時代のチップは、ラジオボタンとチェックボックスの組み立てのまま見た目だけを変え、選んだ状態は隣の要素への指定（`input:checked + span` など）で付ける。
- 下に固定する帯は、画面の流れの最後に置いて `position: sticky` で下に留め、下の安全領域（`env(safe-area-inset-bottom)`）の分も内側の余白に足す。本文の最後まで送れば、帯に隠れない。

## 5. 見直すとき

- デザインの場には、この文書と `src/ui/app.css` の先頭のデザイントークン、全画面のスクリーンショット（幅 375px、ホームは 402px も）を渡す。
- 持ち帰るもの: 変える値（トークン）、ロゴとアイコンの SVG（無ければ 1024px の PNG）、変える画面の見本（幅 375px）。
- 反映したら、幅 375px と 402px のスクリーンショットで見本と見比べ、iPhone の実機でアイコン、上部の時刻の表示の色、判定の帯の動き、数字のキーボードを出したときの見え方を確かめる。
