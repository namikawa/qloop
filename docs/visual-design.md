# 見た目のデザインの前提と制約

QLoop のロゴ・アイコン・配色・画面の見た目を見直すときの前提をまとめる。Claude Design などのデザインの場に渡して方向性を決め、決まった内容をこのリポジトリに実装する。機能の仕様は `docs/design.md` にある。

## 1. アプリの概要

- QLoop は 1 問 1 答で日本史の年表を覚える PWA（ホーム画面に追加して使う Web アプリ）。名前は Question と Loop（くり返し）から。
- 使う人は、中学受験を目指す小学校高学年から大人まで。表示は大人向けの通常の UI でよく、幼い雰囲気にはしない。ふりがなは付けない。
- 使い方は、1 回 10 問ほどの短い出題を毎日くり返す。間違えた問題は「復習」でくり返し出る。
- 端末は iPhone の縦向きだけ。対応の下限は iOS 15.8（iPhone 7、画面の幅 375px）。新しい端末の例は iPhone 16 Pro（幅 402px）。

## 2. 画面と要素

| 画面 | 主な要素 |
|---|---|
| ホーム | アプリ名、教材名「日本史年表」、件数（出題できる出来事 371 件、基本の年表 129 件）、ボタン 3 つ（出題・復習・成績）、下部に版と「アプリを更新」（押すと、その下に「最新の版です」などの結果が出る）。上部に帯が出ることがある（ホーム画面への追加を促す帯、新しいバージョンの帯） |
| 出題設定 | 出題する出来事（基本の年表のみ / すべて）、出題パターン（年号入力 / 4 択 / ミックス）、問題数（10 / 20 / 全問）、範囲（全範囲 / 年号の範囲 / 時代 15 区分の複数選択）、対象の件数、開始 |
| 出題: 年号入力 | 進捗（3 / 10）、終了、出来事の文、「何年の出来事？」、数字の入力欄と「年」と回答。判定欄（正解・不正解、正解の年、次へ） |
| 出題: 4 択 | 「743年の出来事は？」、選択肢 4 つ。判定の後は正解の選択肢を緑、選んだ誤答を赤で示す |
| 結果 | 正答数 / 回答済み数、予定の問題数、間違えた出来事と正解の年の一覧、ホームへ |
| 復習 | 復習する問題の件数、問題数、開始 |
| 成績 | 全体（総回答数・正答率・連続学習日数）、記録の管理（書き出し・読み込み・リセット）、時代別の横棒、出来事別の一覧（371 行。並べ替えと内訳の開閉）、履歴 |
| 確認ダイアログ | 終了・読み込み・リセットの確認（ボタン 2 つ） |

## 3. 守ってほしいこと

画面:

- 幅 375px で横スクロールを出さず、402px でも崩れないこと。縦向きだけを考える。
- 年号入力の問題文と 4 択の選択肢は、全角 15〜30 字ほど（上限 36 字）の 1 文。幅 375px では 2 行になることが多いので、2 行でも読みやすく、選択肢 4 つが 1 画面に収まるようにする。
- 押せる部分の高さは 44px 以上。主な操作のボタン（出題・開始・次へ）は 48px 以上。
- 文字は端末の標準フォント（ヒラギノ角ゴシック）を使う。日本語の Web フォントは数 MB あり、オフライン用のキャッシュが膨らむので使わない。
- 本文は 16px 以上。入力欄の文字も 16px 以上にする（16px 未満だと、iOS が入力のたびに画面を拡大する）。
- 文字と背景のコントラストは 4.5:1 以上（補助の文字も含む。押せない状態の表示は除く）。
- 色の意味を変えない。正解は緑、不正解は赤。主な操作は 1 色にそろえる。
- 写真や大きな画像は使わない。飾りが要るなら SVG で軽く。
- 今は明るい配色だけ。ダークモードは対象外（入れるなら、全画面の配色を 2 通り用意する）。
- 動きは控えめにする。判定の表示などに短い変化を付けるのはよい。

アイコンとロゴ:

- アイコンは正方形で、背景を塗りつぶす（透過にしない）。iOS が角を丸めて切り取るので、四隅に要素を置かず、形は中央に寄せる。
- ホーム画面の小さな表示（約 60px）でも見分けられること。細い線や小さな文字は避ける。
- 書き出すサイズは 512px と 192px（manifest 用）、180px（iOS のホーム画面用）。元のデータは SVG か 1024px の PNG で用意する。
- ロゴは、ホーム画面の見出しの「QLoop」の置き換えに使う。文字をアウトライン化した SVG で用意する。
- iOS の画面上部（時刻などの表示）は、今は白地に黒い文字（`theme-color` と manifest の色が白）。画面の背景の色を変えるときは、これも合わせて決める。

実装の都合（デザインの段階では細かく気にしなくてよいが、凝った表現は避ける）:

- iOS 15.8 の Safari で動く CSS だけを使う。CSS のネスト、コンテナクエリ、`:has()`、`dialog` 要素は使えない。グラデーション、角丸、影、半透明は使える。すりガラスの表現（`backdrop-filter`）は使えるが、古い端末では重くなるので控える。
- スタイルは `src/ui/app.css` の 1 ファイルにまとめている。色や大きさを決まった値（デザイントークン）として持ち込めると反映しやすい。

## 5. デザインの場から持ち帰るもの

- ロゴとアイコンの SVG（無ければ 1024px の PNG）
- 色の値（主な操作、背景、面、文字、補助の文字、線、正解、不正解、帯）
- 文字の大きさと太さ、余白の決まり
- 主な画面の見本（幅 375px）: ホーム、出題設定、出題（年号入力・4 択と判定の後）、結果、成績

受け取ったら、別の PR で `src/ui/app.css`・アイコン・manifest の色に反映し、幅 375px のスクリーンショットと iPhone の実機で確かめる。
